## Description
NetPractice is a foundational networking project that focuses on the practical application of IP addressing, subnetting, and routing. The objective is to configure small-scale networks to ensure successful communication between various devices (computers, routers, and switches) by solving a series of increasingly complex networking puzzles. Through this project, I have gained a deeper understanding of how data packets are routed through a network and how network masks define the boundaries of sub-networks.

## Instructions
### Running the Training Interface
To start the project and practice the levels:
1. Clone this repository to your local machine.
2. Navigate to the project folder and open the `index.html` file in any modern web browser.
3. Use the interactive interface to input IP addresses, masks, and gateway configurations for each level.

### Exporting Configurations
Once a level is successfully solved (the interface indicates all connections are green/working):
1. Click the **Export** button provided in the interface.
2. Save the resulting configuration file.

### Submission Requirements
To complete the project, you must have **10 exported configuration files** (one per level) placed at the root of the repository. Ensure they are correctly named before pushing your final submission.

## Resources
### Networking Concepts Studied
This project involved a comprehensive study of the following concepts:
- **TCP/IP Addressing:** Understanding IPv4 addressing, classes (A, B, C), and the distinction between public and private IPs.
- **Subnet Mask:** Learning how to use masks to divide networks, including FLSM (Fixed Length Subnet Mask) and VLSM (Variable Length Subnet Mask).
- **Default Gateway:** Configuring the point of exit for packets leaving a local network.
- **Routers and Switches:** Understanding the roles of routers (Layer 3) in connecting different networks and switches (Layer 2) in managing traffic within a LAN.
- **OSI Layers:** Familiarization with the 7-layer framework, specifically focusing on the Physical, Data Link, Network, and Transport layers.
- **TCP vs UDP:** Distinguishing between connection-oriented reliability and connectionless, high-speed transmission.
